# HackerRank SQL Solutions (Bản tiếng Việt)

## Giới thiệu
Repository này tổng hợp các lời giải SQL cho bài tập HackerRank, được chia theo từng nhóm chủ đề từ cơ bản đến nâng cao.

Mục tiêu chính:
- Cung cấp câu lệnh SQL đúng và dễ học lại.
- Bổ sung chú thích để hiểu rõ từng thành phần truy vấn.
- Giữ nguyên các từ chuyên ngành (SELECT, JOIN, GROUP BY, CTE...) nhưng có chú thích tiếng Việt.

## Cấu trúc thư mục
- Basic Select: Các truy vấn SELECT cơ bản, lọc dữ liệu và sắp xếp.
- Advanced Select: CASE, CTE, Window Function, xử lý logic phức tạp.
- Aggregation: COUNT, SUM, AVG, MIN, MAX và các bài tổng hợp dữ liệu.
- Basic Join: Kết hợp dữ liệu từ nhiều bảng bằng JOIN.
- Advanced Join: Nhiều mức JOIN, Subquery và tổng hợp nâng cao.
- Alternative Queries: Các bài yêu cầu cách viết truy vấn theo hướng đặc biệt.

## Các chủ đề chính
- Basic Query: SELECT, WHERE, ORDER BY, LIMIT.
- Aggregation: GROUP BY, HAVING, hàm tổng hợp.
- Join: INNER JOIN, LEFT JOIN và các biến thể.
- Advanced SQL: Subquery, CTE, Window Function.

## Hướng dẫn sử dụng
1. Clone repository:
   git clone https://github.com/Vishwas-Chakilam/HackerRank-SQL-Solutions.git
2. Mở thư mục bài cần học.
3. Đọc phần chú thích đầu file để nắm mục tiêu + giải thích thành phần.
4. Chạy truy vấn trong môi trường SQL phù hợp.

## Ghi chú về tương thích
- Hầu hết câu lệnh theo cú pháp SQL phổ biến.
- Một số file dùng đặc trưng hệ quản trị (ví dụ PL/SQL cho Oracle, LIMIT cho MySQL/PostgreSQL).
- Nếu chạy trên hệ khác, có thể cần chỉnh nhẹ cú pháp tương đương.

## Đóng góp
Bạn có thể đóng góp bằng cách:
- Tối ưu truy vấn.
- Bổ sung cách giải khác.
- Cải thiện chú thích/giải thích để dễ học hơn.
